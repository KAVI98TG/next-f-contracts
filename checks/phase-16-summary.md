# Phase 16 Summary

Version: **V0.17.0**

Phase 16 establishes `nextf.site.json` as the single repository-side declaration that connects a customer Site codebase to the NEXT F Contract ecosystem.

## Delivered

- 16 Site Manifest schemas
- 6 canonical descriptive Site types
- 4 environment kinds
- 5 mandatory NEXT F runtime capabilities
- 3 configuration exposure classes
- 3 content delivery modes
- 6 reference Site manifests
- self-contained Draft 2020-12 validation schema
- dedicated Site Manifest Explorer
- source-bound generated fallback
- Codex manifest-first implementation rules

## Core invariant

A customer project may have unique design and business requirements, but it must not invent a parallel NEXT F CMS, event, integration or contract architecture when the Manifest and canonical registry already define the required behavior.

## Next
