# Phase 27 Summary

NEXT F Contracts V0.28.0 adds the Changelog System as the authoritative narrative release-history layer for `contract.nextf.lk`.

The system stores machine-readable release notes under `registry/changelog/releases/`, generates the root `CHANGELOG.md`, exposes categorized release and change-entry search, carries explicit evidence provenance, and links narrative release history to exact Contract Diff and Compatibility Center evidence.

Historical releases without exact Registry snapshots remain explicitly marked as release-notes-only. No history is fabricated. V0.x remains a development foundation train and does not by itself declare production support.
