# Lead Generation Website Reference

Reference composition for a NEXT F **lead-generation** Site using Contract Registry **V0.23.0**.

## Purpose

Create measurable lead funnels where every campaign landing experience can be optimized without fragmenting event names, forms or attribution logic.

## Primary outcomes

- Generate qualified Leads
- Attribute conversions
- Support paid campaigns
- Optimize landing pages
- Protect consent and form data

## Files

- `nextf.site.json` - exact Site Manifest reference
- `CONTRACT-MAP.json` - Modules, Capabilities, contracts, APIs, Events, integrations, roles and permission universe
- `CMS-MAP.json` - Customer CMS and NEXT F Admin navigation/reference composition
- `CODEX-BRIEF.md` - compact implementation handoff
- `ACCEPTANCE-CHECKLIST.md` - reference acceptance gate

## Rule

This is a contract composition reference, not a visual template. Customer-specific UI/UX is still designed and coded for the customer.
