# Ecommerce Website Reference

Reference composition for a NEXT F **commerce** Site using Contract Registry **V0.23.0**.

## Purpose

Build a custom-coded storefront while keeping transactional behavior governed by NEXT F Commerce schemas, rules, APIs, permissions, events and integrations.

## Primary outcomes

- Sell physical/digital eligible products
- Manage catalog and inventory
- Process checkout and orders safely
- Connect payment/shipping providers through adapters
- Measure ecommerce conversions

## Files

- `nextf.site.json` - exact Site Manifest reference
- `CONTRACT-MAP.json` - Modules, Capabilities, contracts, APIs, Events, integrations, roles and permission universe
- `CMS-MAP.json` - Customer CMS and NEXT F Admin navigation/reference composition
- `CODEX-BRIEF.md` - compact implementation handoff
- `ACCEPTANCE-CHECKLIST.md` - reference acceptance gate

## Rule

This is a contract composition reference, not a visual template. Customer-specific UI/UX is still designed and coded for the customer.
